API 调用指南

W-ai-api 兼容 OpenAI 格式，可直接接入任意支持 OpenAI SDK 的应用

基本信息

项目说明
Base URLhttps://api.markbl.de5.net/v1
认证方式Authorization: Bearer 请求头（兼容 x-api-key）
API Key联系服务提供方获取（格式：sk-wa-...）

可用接口

聊天补全

POST /v1/chat/completions 发送对话请求

兼容 OpenAI Chat Completions 格式，支持流式（stream）和非流式响应。

curl -X POST "https://api.markbl.de5.net/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-wa-xxxxxxxxxxxx" \
  -d '{
    "model": "glm-4.7-flash",
    "messages": [
      {"role": "system", "content": "你是一个有用的助手"},
      {"role": "user", "content": "你好，请介绍一下你自己"}
    ],
    "stream": true
  }'

模型列表

GET /v1/models 获取可用模型

返回当前可用的全部模型列表。

curl -X GET "https://api.markbl.de5.net/v1/models" \
  -H "Authorization: Bearer sk-wa-xxxxxxxxxxxx"

文本嵌入

POST /v1/embeddings 生成文本向量

兼容 OpenAI Embeddings 格式。

curl -X POST "https://api.markbl.de5.net/v1/embeddings" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-wa-xxxxxxxxxxxx" \
  -d '{
    "model": "bge-m3",
    "input": "要生成向量的文本内容"
  }'

可用模型

模型名说明
glm-4.7-flash高速轻量化，性价比高
kimi-k2.7-code代码专用，超长上下文
deepseek-coder代码与通用推理
llama-3.2-3b轻量通用对话

接入方式

OpenAI SDK（JavaScript / Node.js）

import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://api.markbl.de5.net/v1',
  apiKey: 'sk-wa-xxxxxxxxxxxx'
});

const res = await client.chat.completions.create({
  model: 'glm-4.7-flash',
  messages: [{ role: 'user', content: 'Hello!' }],
  stream: true
});

for await (const chunk of res) {
  console.log(chunk.choices[0]?.delta?.content || '');
}

OpenAI SDK（Python）

from openai import OpenAI

client = OpenAI(
  base_url='https://api.markbl.de5.net/v1',
  api_key='sk-wa-xxxxxxxxxxxx'
)

stream = client.chat.completions.create(
  model='glm-4.7-flash',
  messages=[{'role': 'user', 'content': 'Hello!'}],
  stream=True
)

for chunk in stream:
  print(chunk.choices[0].delta.content or '', end='')
