关于 W-ai-api

W-ai-api 是一个社区驱动的 AI API 聚合服务，基于 Cloudflare Workers 构建， 接入了多个 AI 服务商，提供 OpenAI 兼容接口， 让你用一套 API 就能调用多种主流模型。

这不是商业项目，而是个人维护的共享服务。如果好用，欢迎分享给更多人。

Python (openai 库)

⚠️ 请逐行手打，特别注意 base_url 的引号内不要多打任何字符（如反引号 `）。也可直接保存为 .py 文件运行。

python 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.markbl.de5.net/v1",
    api_key="sk-wa-9cad3521e2964614bd749b6e1895d58b"
)

response = client.chat.completions.create(
    model="glm-4.7-flash",
    messages=[{"role": "user", "content": "你好！"}]
)
print(response.choices[0].message.content)

📋 常见问题

密钥能用到什么时候？
密钥长期有效。每枚每天 2000 神经元配额，北京时间 8:00 自动重置。当日额度用完即止，次日恢复。
有调用频率限制吗？
没有严格的频率限制，只要当日 2000 神经元额度未耗尽即可正常调用。请合理使用。
能用在自己的项目里吗？
当然可以，个人项目、学习实验、AI 工具都可以直接用。
2000 神经元大概能调用多少次？
以 llama-3.2-3b 为例，输入输出约 1:1 的情况下，一个对话约 4-6 神经元，每天可以调用几百次。高频使用建议自行部署。
