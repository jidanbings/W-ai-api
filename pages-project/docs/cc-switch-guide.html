CC Switch 配置指南

将 W-ai-api 接入 CC Switch 的完整步骤

准备工作

1. 安装 CC Switch

下载安装：

  • Windows: CC-Switch-v3.16.5-Windows.msi

其他平台请前往 GitHub Releases 下载对应版本。

2. 获取凭证

服务开通后，你会收到以下信息：

信息说明
Base URL https://api.markbl.de5.net/v1
API Key 联系服务提供方获取（格式：sk-wa-...）

配置步骤

第一步：添加 Provider

  1. 启动 CC Switch，点击右上角 橙色加号（+） 按钮
  2. 在弹出的窗口中，下滑找到 API Key 输入框
  3. 填写以下内容：
字段填写内容
NameW-ai-api
API Key你的 API Key

第二步：配置路由

必须开启路由模式

否则无法正常使用。具体设置如下：

设置项值
启用路由开启
请求地址
OpenAI 兼容： https://api.markbl.de5.net/v1/chat/completions
Anthropic 兼容： https://api.markbl.de5.net/v1/messages
认证字段ANTHROPIC_AUTH_TOKEN（默认值，无需修改）
请求地址模式完整 URL

两种请求地址格式说明：

格式请求地址适用工具
OpenAI 兼容格式 https://api.markbl.de5.net/v1/chat/completions Codex、Gemini CLI、OpenCode 等
Anthropic 兼容格式 https://api.markbl.de5.net/v1/messages Claude Code、Claude Desktop 等

第三步：配置模型映射（推荐）

把你工具里的模型名映射到可用模型即可，参考以下示例：

工具默认模型映射到
claude-sonnet-4-20250514glm-4.7-flash
gpt-4okimi-k2.7-code
gpt-4-turbodeepseek-coder
gpt-4llama-3.2-3b

其他 Claude 型号同样映射到 glm-4.7-flash 即可。

第四步：保存并激活

点击 Save → 在 Provider 列表中点击 Activate 即可使用。

可用模型

模型名说明
glm-4.7-flash高速轻量化，性价比高
kimi-k2.7-code代码专用，超长上下文
deepseek-coder代码与通用推理
llama-3.2-3b轻量通用对话

验证连接

curl -X POST "https://api.markbl.de5.net/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-wa-xxxxxxxxxxxx" \
  -d '{"model":"glm-4.7-flash","messages":[{"role":"user","content":"Hello!"}]}'

返回正常的 chat.completion 响应即配置成功。

💡 注意事项

  • 网络环境：确保机器可以访问 1.markbl.de5.net，如有需要可配置代理。
  • CC Switch 版本：建议使用 v3.16.0 及以上版本，旧版本可能不支持部分路由功能。
  • 模型映射：如果工具请求的模型不在可用列表中，请先在映射表中添加对应关系，否则请求会失败。
  • 多个 Provider：可同时配置多个 Provider，通过路由规则灵活切换。

常见问题

重新复制粘贴 API Key，注意不要有多余空格，并确保 Key 处于有效期内。

确认目标模型名在可用模型列表中，检查 CC Switch 映射配置是否正确，并确保已保存并激活。

在 CC Switch 列表中激活官方 Provider 即可，无需删除 W-ai-api 配置。

环境变量方式（无需 CC Switch）

# macOS / Linux
export OPENAI_BASE_URL="https://api.markbl.de5.net/v1"
export OPENAI_API_KEY="sk-wa-xxxxxxxxxxxx"

# Windows PowerShell
$env:OPENAI_BASE_URL="https://api.markbl.de5.net/v1"
$env:OPENAI_API_KEY="sk-wa-xxxxxxxxxxxx"
